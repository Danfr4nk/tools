Shared detection: SCRFD (buffalo_l) → 5-point alignment → ArcFace embeddings. Age: ViT-Base bracket classifier (expected age = probability-weighted bracket midpoints) with a genderage regression second opinion. Telemetry: the same 17-ratio MediaPipe vector as the attraction lab. Kinship: cosine similarity on ArcFace embeddings with the heuristic confidence calibration — a resemblance meter, not a test. First run downloads models (~250 MB total); everything is cached by your browser afterwards.
