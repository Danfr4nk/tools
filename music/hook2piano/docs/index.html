hook2piano

TheoryTab → printable piano sheet (LH chords, RH melody)
Paste a full theorytab/view/… link to pick from its sections, or a bare tab ID (e.g. nZgWr__wmry). Pasting a link goes through a public relay that rate-limits, so it can fail — the reliable path is the bookmarklet: open any TheoryTab page and tap ⚡ hook2piano copied. On iPhone: tap copy, then Share → Add Bookmark on any page, edit the bookmark, paste the code into its address field, and run it from the address bar on any TheoryTab page. It reads the tab list straight from the page, no relay needed. First load downloads the Python engine (~10 MB), then everything runs on your phone.
