WHAT THIS PAGE DOES WITH YOUR DATA

It reads the same localStorage keys the instruments already write, under the exact names they already use, and summarises them. It writes nothing unless you confirm a restore. The frame-describe API key is detected so it can be kept out of backups — its value is never rendered on this page.

There is deliberately no service worker: caching this origin would risk serving an instrument a stale model or script, and a broken instrument is worse than a page that loads a beat slower.
